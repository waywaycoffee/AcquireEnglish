# Reading import samples（公版）

Public-domain English books for trying **爱快阅读 → 导入**.

Built from [Standard Ebooks](https://standardebooks.org/) GitHub source trees
(CC0 typography; underlying texts are public domain).

## Files

| File | Title |
|------|--------|
| `alice_wonderland.epub` / `_sample.txt` | Alice’s Adventures in Wonderland |
| `frankenstein.epub` / `_sample.txt` | Frankenstein |
| `dracula.epub` / `_sample.txt` | Dracula |
| `pride_prejudice.epub` / `_sample.txt` | Pride and Prejudice |
| `sherlock_holmes.epub` / `_sample.txt` | The Adventures of Sherlock Holmes |
| `christmas_carol.epub` / `_sample.txt` | A Christmas Carol |
| `treasure_island.epub` / `_sample.txt` | Treasure Island |

`*_sample.txt` = first ~2500–7000 words for a quick TXT import.

## How to import on phone

1. Copy `*.epub` or `*_sample.txt` to the phone (`Download/AcquireReading/` is convenient).
2. Open the app → **阅读** → **导入**.
3. Pick the file (TXT / EPUB).

EPUB binaries may be gitignored if large; regenerate with the helper script if missing.
