## 内测说明全文

### 一、视频学习功能介绍

1. **真实视频输入**：可导入 B 站、YouTube 公开视频链接，也可导入本地视频；书库支持按 B站 / 全英可逛 / 美剧 / YouTube 等分区浏览。
2. **双语字幕精听**：中英字幕同步、倍速、循环单句；缺字幕时可通过语音识别或社区共享字幕补全。
3. **跟读与评测**：影子跟读、看句读、藏句读，录音后给出发音反馈。
4. **配音与分享**：将跟读录音做成配音回放，支持连续播放与导出分享草稿。
5. **听写练习**：听句写英文、提示核对，难题可加入听写队列。
6. **数字人口语外教**：围绕视频字幕生成口语话题，提问、引导回忆并纠正表达。
7. **词卡 / 短语 / 复习**：点词查义、收藏与 FSRS 复习，估计词汇量并自适应难度。
8. **社区与素材**：可浏览全英可逛、热门分享、网盘资源帖、考试资料等；支持 fork / 导入到个人书库。

### 二、视频内容来源与免责声明

爱快英语**不生产、不托管、不出售**第三方影视或博主成片本体。App 内可学习的视频内容主要来自：

- 用户自行导入的 **B 站（Bilibili）**、**YouTube** 等公开平台上的博主作品链接；
- 社区用户分享的学习向链接、字幕元信息、词表说明与网盘学习资源帖；
- 用户本人拥有合法使用权的本地文件 / 网盘文件。

平台仅提供学习工具与索引能力。请内测用户确保对所导入、分享内容拥有相应权利或许可；禁止上传、分享盗版或未获授权的商业影视全集、未授权有声书、未授权考试真题扫描件等。若权利人提出异议，我们将配合下架相关社区条目。因用户擅自分享侵权内容产生的责任，由分享者自行承担。

官方不对第三方平台可用性、字幕准确性、博主内容变更作担保；网络或平台政策变化可能导致部分链接暂时无法导入。

### 三、内测人员的社区共建义务

内测不只是「试用功能」，更是一起把学习素材池做厚。每位内测人员都有义务在合法合规前提下，**持续丰富社区素材**，包括但不限于：

- **网盘视频资源**：在社区发布百度 / 夸克 / 阿里 / 115 等网盘学习资源帖（仅分享你有权分发的链接与说明）。
- **美剧 / 影视学习片段推荐**：推荐适合精听跟读的公开片源或合法网盘学习包，并注明难度与主题。
- **B 站视频推荐**：推荐优质英语原声 / 学习向 UP 主视频，可走全英可逛、热门分享或素材包。
- **阅读小说电子书上传**：向阅读库 / 社区贡献 EPUB 等电子书（须为可合法分发的文本）。
- **有声书**：若贡献有声书，须同时提供对应**音频**与文本（或明确的合法来源说明），便于听读对照。
- **考试材料**：上传可公开或你有权分享的考试向音频、脚本、词表等（社区「考试」页）。
- **书本 / 教材资料**：上传学习用书本资料、讲义或词表；请勿上传受版权保护且未获授权的完整商业教材扫描件。

建议每次内测登录后至少贡献或完善一条社区素材（链接、字幕、词表、电子书或考试资料均可），并在产品反馈里记录卡顿、崩溃与导入失败案例。
