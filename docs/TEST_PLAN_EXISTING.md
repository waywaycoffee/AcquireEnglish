## 0. 怎么用这份计划

| 角色 | 用法 |
|------|------|
| 开发自测 | 每改一域，跑 §1 自动化 + 该域 §3 冒烟行 |
| 发版前 | §1 全绿 → §2 环境检查 → §3 真机 P0 全过 → §4 观感抽检 |
| 回归日 | 按「P0 → P1 → P2」表打勾；失败记入 §7 缺陷模板 |

**判定约定**

- **Pass**：步骤可完成，无崩溃，结果符合「期望」，观感无阻塞级问题  
- **Fail**：崩溃 / 白屏 / 数据丢失 / 付费误锁 / 音视频无法播 / 无法登录  
- **Defer**：已知限制（如微信商户未配、某 GPU 服务未开），记原因，不阻断其它域  

每次真机填写：`commit` · `APK flavor` · `设备型号/Android` · `账号` · `日期`

## 4. 「完善好看」观感清单（全域抽检）

每域至少抽 1 个主屏，按下列打勾。任一 **阻塞** 项 Fail 则该域不通过观感。

### 4.1 阻塞级

- [ ] 无重叠控件、无文字溢出裁切关键信息  
- [ ] 主按钮可点热区 ≥ 约 44dp  
- [ ] 亮/暗主题正文对比度可读（单词卡、字幕、阅读）  
- [ ] 键盘弹出时输入框与主 CTA 仍可见（登录、听写、写作、查词）  
- [ ] 加载超过 2s 有明确进度或骨架，无永久转圈  
- [ ] 错误有中文可读原因 + 可返回  

### 4.2 打磨级（P1/P2）

- [ ] 空态插画/文案引导下一步  
- [ ] 列表滚动无白闪、封面不抖动  
- [ ] 底栏选中态、徽章一致  
- [ ] 成功反馈（领取 Pro、过关、收藏）有统一轻反馈（动效或音效）  
- [ ] Pad 与手机信息架构一致，无「半截桌面布局」

## 9. 快速对照：优先打磨清单（产品视角）

若时间只够修体验，按此顺序：

1. **考试 + 写作**（覆盖差、用户路径完整度差）  
2. **视频字幕补齐与播放跟读**（核心差异化）  
3. **阅读书架 + 查词 + 免费种子**  
4. **复习 FSRS 与词书音频**  
5. **登录/门闸/免费承诺文案一致性**  
6. **口语真机稳定性**  
7. **社区对战与教材课**  
8. **观感统一（空态、键盘、对比度、底栏）**
