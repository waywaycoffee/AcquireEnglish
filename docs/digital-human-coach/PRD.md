# 数字人口语外教陪练 — PRD

> 状态：v0.1（2026-11-14）  
> 证据来源：竞品公开产品面（应用商店文案 / 功能介绍）+ AcquireEnglish 现有管线；**设备抓包待补**（当前无 ADB 设备）。  
> 抓包补全后，本文「竞品对照」与「时序」章节应升版为 `observed`。

## 1. 产品一句话

在观看英文视频的学习场景中，提供可打断的实时口语外教：数字人出镜对话 → 发音/语法反馈 → 错题沉淀 → 延迟复习闭环。

## 2. 用户与场景

| 角色 | 目标 | 主场景 |
|------|------|--------|
| 成人学习者（A2–B2） | 敢开口、说得对、记得住 | 通勤碎片 / 课后跟练 / 考前话题 |
| 视频学习者（AcquireEnglish） | 围绕**当前视频句**练口语 | 播放页「口语陪练」Tab |

## 3. 竞品对照（公开产品面）

### 3.1 Hi Echo（有道，`com.youdao.dict.feature_speaker`）

- **定位**：Agent 口语私教 + 虚拟人出镜
- **实时性**：全双工语音，支持插话打断；对话间隙给发音/语法反馈（不打断表达节奏）
- **内容**：任务地图 / 每日任务；自由聊、话题练、情景角色；15+ 场景、100+ 话题
- **评估**：每轮发音 / 语法 / 润色；音素级纠音 + 音标；学习报告
- **人格**：多虚拟人设定（如 Daniel / Sherry）

### 3.2 Midoo（`com.midoo.ai`）

- **定位**：沉浸式情景 AI 对话
- **内容**：机场 / 餐厅 / 面试等情景；按水平定制方案
- **评估**：练后报告（流利度、发音、语法）

### 3.3 我们要做的差异（AcquireEnglish）

| 维度 | 竞品 | AcquireEnglish |
|------|------|----------------|
| 话题来源 | 通用场景库 | **当前视频字幕 / 课程语境** + 通用任务 |
| 实时底座 | 闭源自研 | **LiveKit Agents**（VAD + 打断） |
| 发音 | 闭源评测 | WhisperX 对齐 + wav2vec2 / 第三方评测 API |
| 数字人 | 自研虚拟人 | MuseTalk / LivePortrait（经 LiveTalking 或直连） |
| 学习闭环 | 任务地图 + 报告 | **ChatterPal 模式**：核对转写 → 原话反馈 → 单句重练 → 间隔复习 |

## 4. 目标流程（用户旅程）

1. **进入**：播放页选「口语陪练」或独立「今日任务」
2. **定目标**：视频跟练 / 情景任务 / 自由聊（三选一）
3. **开场**：数字人问候；展示本轮任务目标（1 句）
4. **全双工对话**：用户可随时打断；外教追问引导多说
5. **边聊边评**（异步、不抢麦）：发音/语法/润色卡片可收起
6. **回合结束**：任务达成判定 + ≤2 条「原话引用」改进点
7. **闭环**：单句重练 / 存入错题本 / 安排次日复习题
8. **报告**：今日开口时长、纠正项、复习到期数

## 5. 功能范围

### P0（必须）

- LiveKit 房间：上行麦、下行 TTS、VAD 打断
- 会话：创建 / 结束 / 历史回合
- 转写：流式 STT +（可选）ChatterPal 式「核对后再提交」
- LLM 外教：角色、难度、追问、纠错文案
- 发音评分：mock + WhisperX 词级对齐骨架 + 第三方 API 适配口
- 数字人播报：TTS 音频 → MuseTalk/LivePortrait/LiveTalking cue
- 错题本 + 间隔复习（ChatterPal 规则简化版）
- App：陪练 Tab 接入 LiveKit token + 反馈卡片

### P1

- 任务地图 / 每日配额
- 音素级可视化纠音
- 多人格数字人形象
- 视频句级「影子跟读 → 升格为对话」

### P2

- 多人房 / 家长报告
- 端侧小模型降本

## 6. 非目标（本期不做）

- 复刻竞品后端协议或破解付费
- 生产级 GPU 集群运维
- 与有道/Midoo 账号互通

## 8. 成功指标（首期）

| 指标 | 目标 |
|------|------|
| 首句到外教开场 | < 2.5s（mock 链路 < 1s） |
| 打断响应（停 TTS） | < 300ms（VAD 触发） |
| 完成一轮任务（含反馈） | ≥ 80% 会话有有效反馈引用 |
| 次日复习回访 | ≥ 30% 存档表达被打开 |

## 9. 合规与隐私

- 录音默认短时保留（对齐 ChatterPal：临时回放 / 可选延长）
- 云 ASR/LLM/TTS 明确告知并走用户自备 Key
- 竞品分析仅用于产品设计，不复制受保护资源与密钥
