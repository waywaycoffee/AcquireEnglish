# 英语水平估计（App 内）

> 状态：方案已采纳（2026-11-26），尚未实现。  
> 用途：今日之旅按能力推难度；进步页分开画「水平」和「投入」。  
> 不对外声称正式 CEFR。题库难度和档位边界验证之前，文案写 **「约 B1 · App 内估计」**。证据不够的维度写 **「校准中」**。

现有起点：自适应词量测试（约 16 题 → 词形估计 → 粗 CEFR）、水平页一次合成（词量 40% + 阅读小测 35% + 一句跟读 25%）、阅读生词边界 `freqThresholdForVocabEstimate`。这些是先验，不是持续水平。

---

## 1. 三条能力，分开估计

认词、听懂、读懂各自一条估计。口语 / 跟读先不参与升档。

| 能力 | 可以升降档的证据 | 只用来决定「测哪里 / 推什么」 |
|------|------------------|-------------------------------|
| 认词 | 同一词频段里**未练过的词**，**首次**作答能否认出释义 | FSRS 说明练过的词记得牢不牢，并提示该去哪个词频段抽测 |
| 听力 | 听一段**已标注难度**的短音频，先收起字幕，再答主旨或细节 | 暂停、回放、开中字说明需要多少辅助。跟读重合度评的是复述，单靠它不能判断听懂 |
| 阅读 | 读完一段**已标注难度**的文章，答主旨或细节，并记下答题时用过的辅助 | 每百词查词、完读率只能提示是否吃力。爱查词或跳着读会产生同样的数 |

同一个词当天复习三次，仍然只算 **一个词** 的证据，而且只记首次作答。

## 2. 综合档怎么用

「取最弱项」只决定**综合学习从哪练起**，不把所有内容都压到最弱档。

例：认词约 B2、听力约 A2、阅读约 B1。

- 首页可突出「当前优先练听力」
- 背单词按认词档（约 B2 前沿）抽
- 视频推听力档：A2，或少量 B1
- 阅读仍推阅读档：B1

这样短板看得见，也不会因为听力弱就一直读过于简单的文章。

## 3. 首版顺序

### P0 · 认词闭环（先验证这一件）

背熟一批词之后，用户能不能认出**同一难度的新词**。

1. 每日复习结果只用来找最值得抽测的词频段。
2. 在几次学习里穿插少量该段**未练过**的词，只记首次作答。
3. 攒够证据再升降。约 80% 正确可作为试运行阈值，同时要求：来自**不同日期**、**多个独立词条**。单次表现差先观察，不立刻降档。
4. 新用户显示「约 B1 · 校准中」（自报或词量测试只作起点）。进步页写清依据：抽了哪一档、多少新词、首次正确率。

### P1 · 听读理解

每隔几次学习插入一两道短题，优先抽该能力的当前档和相邻一档。规则与认词相同：独立题目、首次作答、跨日、够量才升降。

### 进步页

- **水平**：三条能力按周汇总的有效证据趋势；不足则「校准中」
- **投入**：背词数、观看分钟、阅读词数，单独统计，不拿来升档

## 4. 和今日之旅的关系

无目的用户的固定顺序仍是 **背单词 → 视频 → 阅读**。难度按场景取对应能力，不按综合最弱项一刀切：

| 推的内容 | 用哪条估计 |
|----------|------------|
| 背单词 | 认词 |
| 视频 | 听力；听力仍在校准时，暂用认词档并标「校准中」 |
| 阅读 | 阅读；阅读仍在校准时，暂用认词档并标「校准中」 |

有目的的短名单仍由用户点选。AI 排序可以用「是否落在 i+1」作理由，稍难的标出来，不占无目的用户的默认位。

## 5. 算法目标：下次还想学，而且是 i+1

不优化停留时长。每次只推一条「愿意开口学」且「比当前能力略难一档」的内容。太熟的不占默认位，难两档以上的只出现在「换」里并标「稍难」。

词频上的 i+1 已有雏形（`iPlus1LearnScore`）：远低于前沿的词几乎不拿来新学，刚好越过前沿的优先。视频、阅读、口语用同一窗口，只是尺子不同：

| 模块 | 尺子 | 默认窗口 | 太简单时 | 太难时 |
|------|------|----------|----------|--------|
| 背单词 | 认词前沿 | 当前词频段往上一点的**新词** | 不再当新学，只进复习 | 不进默认抽卡 |
| 视频 | 听力档 | 当前档，或少量高一档 | 不作为无目的默认 | 只进短名单并标稍难 |
| 阅读 | 阅读档 | 同上 | 同上 | 同上 |
| 口语 | 口语档；还在校准时暂用听力档，并标明 | 场景难度 = 当前档或高一档 | 换一个新任务，不重复上一句台词 | 缩短教练句子、多给支架，而不是直接升场景 |

「还想学」只看选择，不看暂停和查词：点了短名单里的哪条、是否接着追同一系列、是否点了「换」。这些用来排序；i+1 用来否决过易或过难的默认项。两者都满足才放上主按钮。

### 口语不要每次同一句

现在情景种子和开场白是固定的（例如餐厅永远是 “Order food and a drink…”）。难度字段有，但开场不跟水平变。

每次开口前：

1. 选一个难度落在口语 i+1 的场景；同一场景若昨天刚练过，换成同难度的**另一条任务**（点餐 → 改口味 / 分开买单），不复读同一句 prompt。
2. 把最近几天用过的开场白和目标句放进「不要重复」。
3. 塞进 1–2 个刚好在认词前沿上的词或句块，让台词跟着词汇走。
4. 支架随档变：低档教练句子短，卡住再给半句；高档少给全文，多追问原因和观点。
5. 口语升档同样靠新任务的第一次完成（目标达成、少量提示），不靠把同一句跟读到高分。

## 6. 要不要记忆体、个人知识库、小模型

要一份**结构化长期档案**，不要对话向量库，首版也不要专门的分析小模型。

| 存什么 | 作用 | 不存什么 |
|--------|------|----------|
| 认词 / 听力 / 阅读 / 口语四档 + 置信度 + 上次抽测日 | i+1 窗口 | 把停留时长当成水平 |
| 词的 FSRS（已有） | 复习和「该抽哪一段」 | 把练过的词再当成新证据 |
| 在追的课 / 剧 / 书，以及最近点选、点「换」的内容（换掉的数天内降权） | 下次更想学 | 全量浏览日志当兴趣 |
| 近 7 天口语用过的场景、任务和开场白；本周要塞进台词的前沿词 | 不重复台词 | 全部历史对话原文 |

这就是长期记忆：一条可更新的学习者 JSON（或现有进度表上的字段）。个人知识库如果指「把用户说过的话做嵌入再检索」，首版不建。口语不重复，靠上面那张「用过的句子」名单就够。

小模型以后只做一件口语的事：在档位、禁止重复的句子、1–2 个目标词都给定时，写一句新台词。兴趣排序和升档仍用规则和抽测正确率。等短名单日志证明规则经常排错，再考虑很小的排序模型。不用模型来「判断用户现在是 B1」。
