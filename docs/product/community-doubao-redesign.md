# 社区重设计（对标豆包协作社区）

## 2D 形象为什么「消失」了？

**没有删掉。** 纸娃娃系统仍完整存在：

- 资源：`apps/mobile/assets/img/avatar_cartoon_{1..6}.png`
- 组件：`AvatarPreview` / `AvatarShopScreen` / cosmetics API
- 仍展示：学习桌、一起练、背诵「我的形象」

社区改成「冒险广场」后，Feed / 热门 / 找人卡片改成了 **play 图标 / 首字母头像**，API 仍返回 `author_avatar`，但 UI 不再渲染。本次已把 Feed 卡片重新挂上 2D 形象。

> 注意：口语外教的 `cartoonDigitalHuman` 是另一套数字人，与社区纸娃娃无关。

---

## 产品定位（锁定）

**不是打卡灌水社区，是「素材 + 语言输出」可溯源协作社区。**  
社区内容尽量能导入播放器 / FSRS / 词表；弱化时长 PK、连续打卡榜。

保留现有咖啡店闯关、学习桌、一起练，但降为「小组 / 练习」入口，不再占据社区主叙事。

---

## 信息架构（MVP）

| Tab | 职责 | 现状映射 |
|-----|------|----------|
| **冒险** | 游戏化主入口：咖啡店地图、学习桌、一起练积分装扮、可开练任务流 | `ExplorationMap` + `StudyPlay` + quest feed |
| **素材** | 分享字幕/词表/B 站任务；CEFR 筛选；收藏 / fork（P1） | 热门分享 + `share_bilibili` |
| **练习** | 成果动态、仿写、跟读投稿 | Feed：`learning_result` / `method` 等 |
| **问答** | 发音/词汇/语法问题，可嵌台词与词卡 | Feed：`question` |
| **我的** | 2D 形象、作品、关注/收藏、形象商店 | cosmetics + social |

顶部文案：**学习社区** · 冒险闯关 · 素材协作 · 输出互评。  
底部导航主栏保留「社区」，避免游戏化藏进「更多」。

## 分期

### P0（本次）
1. 恢复 Feed / 卡片 2D `AvatarPreview`
2. 顶栏改为 素材 / 练习 / 问答 / 小组 / 我的
3. 「我的」资产主页壳（形象预览 + 商店 + 社交入口）
4. 文档与导航文案对齐定位

### P1
- 素材包模型（字幕时间轴 + 词表元信息 CEFR/口音/题材）+ fork 到本地库
- 仿写 / 跟读投稿 kind + 批注互评模板
- 问答贴可嵌入词条 key / 片段 timestamp

### P2
- 正式小组实体、组内任务、口语角存档 → 生词入库
- 信用（fork 数 / 有用点评），不做金币段位
- FSRS 卡面关联社区讨论

### 明确不做
- 连续打卡排行、时长 PK 主叙事、强制每日必发

## 跨模块联动（差异化）

1. 素材 → 播放器 + FSRS 词表  
2. 点评指出的表达 → 一键入词库  
3. 讨论例句 → 卡片备注带讨论链接  
4. 复习词条时展示相关社区问答 / 仿写
