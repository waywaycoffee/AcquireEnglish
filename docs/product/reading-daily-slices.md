# 长篇 · 日更切片（Serial Slices）

**问题：** 名著/小说一次太长，用户容易放弃。  
**解法：** 看起来像「每日更新一篇」，其实是**同一本书按序切出的今日片**；读完强制/引导做一小段练习，再解锁次日片。  
**对齐：** 首页「今日学习 · 阅读配额」连续性（接着昨天的书）；木纹书架仍是整书入口。

更新：Asia/Shanghai 2026-11-28。

---

## 1. 用户感知 vs 实际结构

| 用户看到 | 系统实际 |
|---|---|
| 「今日阅读 · 绿野仙踪 · 第 12 片」像日更短文 | `bookId` 固定，`sliceIndex=12`，正文 = 长篇连续区间 |
| 发现栏「每日一文 / 名著精读」每天换一条卡 | 卡绑的是**该用户在追书的下一片**，不是新书 |
| 读完弹出「今日练习」 | 本片 quiz（已有 `ReadingPageQuiz` / 伴读出题） |
| 书架上一本完整封面 | 整书进度条 = 已完成片数 / 总片数 |

像追剧：一季长剧 → 按集播；这里一本书 → 按片读。

```
整书 (ReadingSeries)
 ├─ Slice 01  … 今日露出 / 可练
 ├─ Slice 02  … 解锁条件：01 读完+练习达标（或仅读完，见策略）
 ├─ …
 └─ Slice N   … 全书完 · 可发证书/社区打卡
```

---

## 2. 怎么切（切分规则）

优先级：**可读完 + 落在阅读配额附近**，不要按印刷章生切到一半对话。

| 规则 | 建议值 | 说明 |
|---|---|---|
| 目标词数 | **400～800 词/片**（对齐今日阅读配额 300/500/800） | 一片 ≈ 一天配额 |
| 上限 | ≤ 1000 词 或 ≤ 8 分钟朗读 | 超时拆两片 |
| 切点 | 段落边界 → 场景边界 → 章节边界 | 禁止句中切断 |
| 章内多片 | `Ch.3 · 2/4` | 大章继续切 |
| 短章合并 | 两章合计 < 350 词可并一片 | 避免碎片 |
| i+1 标注 | 片级生词率；过高则「精读模式」或提示查词 | 不因难而跳片 |

**切片产物（ECS / 本地均可）：**

```json
{
  "seriesId": "wizard-of-oz",
  "title": "The Wonderful Wizard of Oz",
  "sliceIndex": 12,
  "sliceTotal": 48,
  "label": "第 12 片 · 黄砖路",
  "chapterRef": "Chapter 4",
  "wordCount": 612,
  "charStart": 18420,
  "charEnd": 22105,
  "plainText": "...",
  "prevSliceId": "wizard-of-oz#11",
  "nextSliceId": "wizard-of-oz#13"
}
```

整书仍存一份 canonical 文本；片只存偏移 + 元数据（或预生成 `plainText` 缓存）。导入书首次打开时后台切分。

## 3. 「日更」怎么露脸（不靠外网新书）

| 入口 | 行为 |
|---|---|
| **首页 · 今日学习 · 阅读** | 「下一步」→ **在追书的下一片**（连续性优先，见 english-journey-prd） |
| **发现 · 每日一文 / 名著精读** | 有在追 → 推「续读 · 今日片」；无在追 → 推可开坑的短首片（试读 Slice 01） |
| **木纹书架** | 封面角标 `12/48`；点进 = 阅读器定位到当前片；可「浏览全书」 |
| **历史** | 「昨天读到第 11 片」一键续 |

日更感来自：**每天换一片卡 + 日期角标「今日」**，内容源是该书队列，不是 B 站式抓新。

## 4. 读完 → 练习（片尾闭环）

每片结束屏（阅读器末页或 overlay）：

1. **本片完成**（词数计入今日阅读配额）  
2. **今日练习**（必做或强引导，默认强引导）：  
   - 理解 2～3 题（细节 / 主旨）— 复用 `reading_page_quiz` + 伴读出题  
   - 词汇 1～2：本片高亮生词进 FSRS（白名单可跳）  
   - 可选：跟读 1 句 / 朗读本片摘要  
3. **结果**  
   - 达标 → 「明天继续第 N+1 片」+ 可提前解锁「再读一片」（VIP/精力）  
   - 未达标 → 可重做；不挡回顾本片，默认不提前开下一片  

**与「今日复习」分工：** 片尾练习 = **新学闭环**；错词/弱项次日进 FSRS「今日复习」，不塞进片尾变长。

```
打开今日片 → 阅读（可点词）→ 片尾练习 → 记账配额
                              ↓
                         生词 → FSRS
                              ↓
                         解锁次日片 / 或「再来一片」
```

## 5. 解锁与防弃读

| 策略 | 默认 |
|---|---|
| 顺序解锁 | 是（防剧透乱跳） |
| 漏读补看 | 可回看已完成片；未解锁不可跳 |
| 请假 | 断签不重置进度；回来仍续下一片 |
| 弃读救援 | 连续 2 天未打开在追书 → 首页卡改文案「就 6 分钟 · 第 N 片」并缩推荐词数档 |
| 换书 | 书架可暂停本系列；发现可开新坑（旧进度保留） |
| 全书完成 | 庆祝 + 练习总复盘 + 社区可分享 |

## 6. UI 要点（暗色 coral / 亮色 teal）

### 6.1 今日片卡片（首页 / 发现）

- 左：书封面小图  
- 中：书名 · `第 12/48 片` · 约 6 分钟 · 词数  
- 右：进度环  
- 角标：**今日**（coral）  
- 副文案：上一片标题回顾一行（连续性）  
- CTA：**继续读**

### 6.2 阅读器顶栏

- `黄砖路 · 12/48` + 细进度  
- 不显示吓人的「全书还剩 80%」为主信息（可次级）

### 6.3 片尾练习页

- 短；3～5 题；底栏「提交并结束今日阅读」  
- 通过后：木纹书架该书进度前进一格的动效（轻量）

### 6.4 书架

- 木纹视觉**不改**；仅封面加 `12/48` 或书脊进度条

## 7. 和现有模块的挂接

| 已有 | 挂法 |
|---|---|
| 今日学习阅读配额 | 一片词数 ≈ 一档配额；完成片 = 进度 |
| `ReadingDoc` / segments | 片 = 有界 segment 组或独立 doc `seriesId+sliceIndex` |
| `reading_page_quiz` / 伴读出题 | 片尾练习主引擎 |
| FSRS | 片内收藏词 → 复习轨 |
| 发现栏目「名著精读」 | 卡片数据源改为「用户下一片」优先 |
| Standard Ebooks / 导入书 | 入库后跑切分任务 |

## 8. 不做

- 不把整本 EPUB 一屏丢给用户当「今日任务」  
- 不用假「每日新书」掩饰续读（可写明「连载阅读 · 今日片」）  
- 片尾不做长模考（考试阅读另栏）  
- 不改木纹书架材质
