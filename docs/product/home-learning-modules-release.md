# 首页学习模块交付与剩余依赖

本轮把六个模块都接到可操作的流程，不再仅提供首页入口。

| 模块 | 功能 |
| --- | --- |
| 词书 | 现有云端下载、本地导入、名称/主题搜索、切换保留记忆、已有词书继续学习与FSRS |
| 国际音标 | 入门音素对比、例词示范、提示收起、听辨检查；完整书库与现有口语训练入口 |
| 自然拼读 | 字母/组合规则提示、合音完整词示范、识别题；完整拼读书库入口 |
| 应用语块 | 场景表达、替换例句、自定义表达试听、理解题、收藏复习 |
| 磨耳朵 | 默认隐藏字幕、分句/全文播放、循环、语速、10分钟定时停止、理解题 |
| 场景对话 | 两个角色、逐句示范、角色提示、理解题、衔接餐厅/酒店语音或文字外教 |

课程现扩展为128个自编单元：46节音标（原对比课2节＋传统英式教学音标44项）、32节拼读、22节语块、14节听力、14节场景。保留原课程顺序，新增单元追加，避免旧位置错位。覆盖有限的基础课程体系，不能宣称涵盖所有口音、考试词汇或全部生活场景。

音标体系参考 British Council 的教学音标图：https://www.teachingenglish.org.uk/teaching-resources/teaching-secondary/teaching-tools/phonemic-chart-english-teachers 。词例和中文提示自行编写，没有复制来源课程正文或音视频。近央双元音注明现代英式合流差异，基础模块示范选择英式语音。

完成理解题后保存本模块下一课位置，按账号隔离，本机重启可读。收藏保存到原表达库，交给原复习系统安排；不复制他人记忆、不自动发布、不发打卡积分。新增JWT保护的 `/api/learning-modules/{kind}/progress`，保存课号、句号及已完成集合；修订号CAS拒绝旧设备覆盖，客户端同步时合并完成集合。离线先保存本机，登录后可重试；切换账号清空当前状态。

示范是ECS口语服务合成的完整词/句，App在线播放、不打包音视频，不将合成字母名称当音素示范。现有媒体接口已具备，但线上foundation媒体清单当前为空，不能把接口能力当成已有真人素材。新页面没有自动发音打分，语音/文字训练调用既有外教页，其网络服务可用性按原功能处理。没有假装新实现真人口型或音素级强制对齐评分。

用户可在后台切换/退出时停止音频；错误提示可重试。答题未正确不能完成本课；保存失败保留当前位置。原学习数据及其他任务的未完成文件不清理。

## 尚未具备的外部条件

- 原外教服务的发音provider为simple，只作ASR词句匹配；本轮新增独立腾讯云评测接口，不用原phoneme代理指标冒充声学评分。已按用户选择实现腾讯云SOE录音评测及逐词/音素结果。真实联调仍需要配置凭据并开通服务。
- 真人口型视频和独立音素/分音发音素材需要可使用的来源，目前没有现成媒体清单。已有文字发音指导及整词合成示范不冒充这些素材。
- 场景外教现在带入所选课程、对话和角色，提供现有AI反馈；该反馈受服务器可用性及原有会员/额度规则约束，不承诺专业测评认证。

验证：88项App相关测试、云端进度隔离及CAS冲突测试通过。尚缺的两项外部条件已向用户说明，不能写成“全部完成”。

## 腾讯云接入（新增）

- 新增服务端SOE签名、鉴权录音入口、16kHz/16bit/单声道PCM格式校验、录音长度上限、每用户调用限速和并发限制。主密钥不下发App。
- 各课程页面增加麦克风授权、开始/结束录音、上传、错误重试、原始总分/准确度/流利度/完整度和逐词音素明细。用户明确点击录音后才请求权限及发送录音；切换账号丢弃旧响应。
- 配置：ECS API `.env` 设置 `TENCENT_SOE_SECRET_ID`、`TENCENT_SOE_SECRET_KEY`，腾讯云账号需开通SOE。当前未发现配置，线上只能验证未配置提示，不能宣称已完成真实付费评测联调。
- 官方接口与格式依据：https://cloud.tencent.com/document/api/884/32605 。采用基础版非流式 `TransmitOralProcessWithInit`，保留腾讯云返回的逐音素结果，缺失结果不伪造。

## 2026-11-21 配置与联调复核

旧记录中的“腾讯云未配置”已不再代表当前服务器状态。此次在 ECS 检查确认腾讯云与阿里云配置存在，未输出任何凭据。用已有阿里云合成示例音频（不是用户录音）转换为16kHz单声道PCM，经当前评测入口发往腾讯云，成功返回 `tencent-soe`、数值评分及5个单词的结果。此项验证了服务联通，不代表真人发音质量验收，也不写入用户学习成绩。

本次阅读收尾：书架六项统计改为一行，使用细分隔线、不加大卡片；保留完整数值的无障碍标签和长按提示，大数显示“万”。深浅主题及320/390宽度均有测试。阅读正文已修复与App主题混用导致的浅底白字，阅读页顶部封面已移除。Pencil深浅主题单行方案已保存。Standard Ebooks的GitHub书籍源压缩包及其codeload跳转也通过ECS白名单缓存转发。

仍保留的边界：当前阅读句内逐词高亮按音频播放进度估算，尚非声学逐词时间戳。角色分层素材、评论专项举报等复习与社区后续边界继续见 `review-community-implementation.md`，不因阅读收尾而视为已交付。
