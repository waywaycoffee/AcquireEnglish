# 爱快英语社区规划与冷启动方案

## 定位与核心闭环

社区服务于「发现一个值得学的内容 → 导入学习 → 分享收获 → 获得反馈 → 与同水平用户持续学习」，不建设泛娱乐信息流。核心指标是社区带来的有效学习天数、内容到学习转化、次周留存，而非浏览时长。

## 当前实现审计

已具备：动态、榜单、找人、热门四个入口；兴趣标签、英语水平和关注博主设置；B站视频分享、组队邀请、产品反馈三类发帖；点赞、评论；学习时长/词汇榜单；相似用户、个人社区资料、词汇PK；热门分享与博主；分类纠错申请及审核接口。

证据：`apps/mobile/lib/features/community/presentation/`、`services/api/app/routers/community.py`。现有接口包括 feed/posts/like/comments/study-stats/leaderboard/similar-users/hot-shares/hot-creators/pk/me/reclassify-requests。

缺口：缺少完整关注用户关系、收藏、通知、活动/小组生命周期、举报与拉黑闭环；阅读到学习的转化埋点不足；列表未形成统一分页、过滤和去重体验；未登录主要为空态。现有 seed 仅首次空库写入同一个助手的3条帖子，不能代表真实用户关系或社区最终形态。学习统计来自客户端同步，直接奖励或排名前需完善可信时长与异常检测。

## 信息架构与行为

| 模块 | 内容与关键操作 | 边界与验收 |
| --- | --- | --- |
| 发现动态 | 推荐/关注/同水平；视频、打卡、方法、问答、搭子、反馈；搜索和筛选 | 列表分页去重，保留筛选；未登录可浏览合规公开内容 |
| 帖子详情 | 作者、等级、学习来源、视频卡、正文、评论；点赞、收藏、导入学习、举报 | 分享卡必须校验真实来源；删除/审核下架后显示不可用，不跳转失效链接 |
| 学习搭子 | 相同水平、兴趣、可用时间；资料、关注、申请组队 | 双向同意后建立组队；拒绝、撤回、退出、拉黑；默认不公开联系方式 |
| 学习榜单 | 周学习、坚持天数、词汇成长；个人进度 | 用户可退出榜单；有效学习时间封顶，异常统计不计奖；时区、周期明确 |
| 活动广场 | 挑战、共读、精听主题；报名、每日任务、进度、结营 | 未开始/进行中/已结束；重复报名幂等；奖励规则版本化、服务端发放 |

| 管理后台 | 审核队列、举报、申诉、屏蔽词、种子内容、活动、运营指标 | 角色权限、审计日志、限流；操作不可由普通用户接口调用 |

## 主要数据模型与接口增量

沿用 CommunityPost/Comment/Profile 和现有PK模型；新增 Follow（follower/followee唯一键）、Bookmark（user/post唯一键）、Block、Report（原因/证据/处理状态）、Notification（收件人/已读/去重键）、Challenge/ChallengeMember/ChallengeCheckin、PartnerRequest。帖子增加审核状态、可见范围、删除时间和来源标记。所有互动写接口认证、校验归属、幂等、防重复；列表用游标分页，避免榜单/动态大量全量查询。

评论支持回复与分页；关注/收藏用 PUT/DELETE 表达目标状态；举报不向被举报人暴露举报者。通知仅发送真实事件，自己操作不通知自己；拉黑后双方不可继续发起搭子请求。

## 冷启动展示（本次交付）

真实社区工具栏新增「社区全景预览」，未登录也可打开。独立内存数据，不写生产库、不创建虚假账号、不冒充真实活跃用户。顶栏持续标注 mock，退出重置。保留真实社区与当前种子帖子，不自动把 mock 混入线上推荐或榜单。

包含6类帖子、不同英语水平与兴趣人物、示例视频卡、评论、不同强度学习记录、搭子卡、挑战活动和榜单。支持筛选、点赞撤销、收藏撤销、发布演示帖、评论、关注切换和加入/退出演示活动。未接入举报等能力用明确说明，不伪装请求成功；视频卡不冒用真实BVID。

演示是目标形态的交互样板，关注/活动等生产能力仍按下列阶段实现，不视为已经上线。

## 分期实施和优先级

### P0：上线前的可靠性与内容质量

统一加载/空态/断网重试、列表分页、发布校验与频控、删除、举报、拉黑、管理员审核；完善视频来源/版权说明和导入学习的结果反馈。校验所有接口归属与敏感资料可见性；统计接受可信播放心跳、去重会话、单日上限、反作弊后才计奖。验收包括越权、重复操作、断网重试、审核下架、匿名浏览权限。

### P1：学习互动闭环

真实关注/收藏、回复和通知、用户主页、搭子申请/接受/拒绝/退出；正式添加方法和问答类型，兼容旧客户端类型映射。事件埋点：曝光、详情、导入、首次有效学习、发帖、收到回复、再次学习。验收：从推荐内容到完成学习再分享，双账号完整跑通；被拉黑和退出后停止关系通知。

### P2：活动与可持续运营

7天跟读活动、主题共读、小组进度和结营；奖励与会员券服务端账本绑定；加入、签到、奖励唯一约束防重复；活动规则发布后留版本。管理员可暂停活动与撤销异常奖励，向用户显示原因和申诉入口。

### P3：推荐和增长

以兴趣/水平/真实有效学习反馈排序；提供「不感兴趣」，保留探索内容和新作者曝光。避免只按点赞排行，不以付费会员身份压制普通用户内容。

## 冷启动运营节奏

上线前邀请10–20名真实内测用户，明确身份；官方账号准备30条可验证视频推荐、10篇方法、5个问答和2场小挑战。每个示例与官方内容都标明来源。首周每日保证新人问题获得回应，第二周按「导入后实际学习」筛选优质帖子。没有真实用户时展示官方内容与空态，不制造伪造人数。

观察每周内容导入率、导入后有效学习率、首帖获得回应比例、搭子双方接受率、活动完成率、举报处理时延和社区用户次周学习留存。先记录基线，再确定目标；mock 数据不进入这些指标。

## 验证与交付边界

本次交付代码为隔离演示入口与交互样板，生产社区现有能力保留。演示测试覆盖筛选、点赞/收藏切换、mock标识与退出入口；构建正式包名 APK 安装到在线手机。后续P0–P3按接口和数据迁移逐步实现，不能把演示点赞/评论等当作已经持久化的正式功能。
