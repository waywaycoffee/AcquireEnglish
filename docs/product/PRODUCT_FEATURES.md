# AcquireEnglish 产品功能说明

> 版本对应仓库主线能力（以代码落地为准）。面向产品、运营与协作说明「用户能做什么」。  
> 相关专项文档：`MEDIA_ECS.md`、`PREGEN_CACHE.md`、`community-prd-v2.md`、`home-learning-modules-release.md`、`miniprogram-v1.md`。（`community-adventure-ui.md` 已作废）

---

## 1. 产品定位

AcquireEnglish（爱快英语）是一款以**真实视频精听**为核心、叠加**泛读、词汇记忆、数字人口语、考试备考与社区协作**的英语习得应用。

- **主路径**：导入影视课 → 逐句精听 / 影子跟读 → 词句进词书 → FSRS 统一复习  
- **辅路径**：爱快阅读、零基础模块、数字人陪练、考试备考模式、社区真题共享与同桌 PK  
- **架构原则**：音视频只存 ECS，经 API 流式播放，不打进 APK

## 3. 账号与会员

- **引导**：首启选择学习目标与难度（`/onboarding`）

## 4. 学习首页

- **今日学习**：三配额（视频/单词/阅读）+「下一步」接着昨天；详见 `english-journey-prd.md`
- **今日复习**：统一 FSRS 到期列表（不含新课 / 新词）；新学走「今日学习」
- **继续学习海报**：最近视频集或词书进度一键续学（优先真实封面，避免占位图标）
- **最近课程**：多门课进度条
- **每日 / 焦点推荐**：按偏好推视频或阅读
- **零基础快捷入口**：音标、拼读、语块、磨耳朵、场景对话、真人口语
- **导入入口**：B 站 / YouTube / 本地 / 网盘

## 5. 视频学习与导入

### 5.1 视频库

- 课程网格/列表、排序、CEFR 筛选、搜索、编辑
- 课程详情与集进度、难度标注
- **推荐 B 站发音博主**：点视频即导入；可显示「云端已备字幕」
- 云端目录 + 本机导入 + YouTube 导入分区展示
- 打开播放器、全文稿阅读、字幕补齐状态

### 5.2 导入课

| 来源 | 能力 |
|------|------|
| B 站 | 单集/合集链接；解析、下载或流式；Cookie（设置） |
| YouTube | 粘贴链接导入学习资产 |
| 本地 | 视频 + 字幕匹配入库 |
| 网盘 | 百度/夸克 Cookie 或 token，服务端解析 |

导入后进入**闲时字幕补齐队列**（缺英 ASR、缺中翻译等），不在打开播放器时现场拖死进程。

## 6. 精听播放器

路径：`/episodes/:episodeId`（支持起播时间、自动播放、全屏、单句循环等）

| 能力 | 说明 |
|------|------|
| 追剧 / 精听模式 | 追剧少打断；精听打开学习壳 |
| 字幕 | 中英轴、点词、长按短语、语块高亮、横竖屏 |
| 影子跟读 | 录音、句末停、评分、回放；可进 FSRS |
| 听写 | 逐句听写与 diff；可进复习队列 |
| 数字人 Tab | 基于本集字幕上下文口语陪练 |
| 练习 / 背单词 Tab | 理解练习、本集词表、今日背词入口 |
| ASR | 官方轨 → 共享字幕 → 云端 GPU 生成 |
| 硬字幕 OCR | 帧采样 OCR 补英文硬字幕轴（不覆盖官方中文软字幕） |
| 发音评测 | 可选腾讯云 SOE（服务端配置） |
| 云共享 | 登录后高质量字幕包可上传共享 |

## 7. 爱快阅读

路径：`/reading`、`/reading/catalog`、`/reading/:docId`

### 7.1 书源

- **在线书库**：OneStop、CEFR、Magic、Standard Ebooks 等按需下文本
- **本地导入**：`.txt` / `.md` / `.epub` / `.mobi` / `.azw` / `.azw3` / `.pdf`
- **扫描 PDF**：文字层不足 → 查云端 OCR 库 → 本机 OCR（约 120 页上限）→ 登录后上传共享（按文件 sha256）
- **从视频生成**：选带英文字幕的课集合成短文

### 7.2 阅读体验

- 点词查义 / 收藏、语块双击、词频灰字、沉浸 / 精读模式
- **连续朗读** + **男女声**（阿里云 CosyVoice，ECS/陪练内容寻址缓存，失败回落本机 TTS）
- **数字人悬浮球**：拖动、语音/文字提问，带文章上下文
- **i+1 推荐**：按生词率约 2%–8% 排序
- **黑白名单**：白=已会，黑=强制关注；与复习词合并
- 慢读、可选 SOE、阅读统计

## 8. 背单词与统一复习

路径：`/review`、`/review/session`、`/review/sm2`、`/review/learning`、`/vocabularyPlacement`

- **复习枢纽**：今日到期/新学、继续复习、来源分组、词汇量参考、形象与商店入口
- **FSRS 多源合并**：单词、短语、表达、听写错句、跟读低分等；考试错题可回流同一引擎
- **考试会话**：按 `exam:{familyId}` / 词书 `examTag` 过滤；不 fork 第二套调度器
- 自由练习 / 薄弱项 / 词书单元 / 推荐 deck
- SM2 词书会话、学习表达复习、词汇量测评
- 登录后可同步口语错题与到期摘要

---

## 8b. 考试备考模式

路径：`/exam`、`/exam/select`、`/exam/practice`、`/exam/mock`、`/exam/errorbook`

- **双模式**：日常习得 / 考试备考（设置与 onboarding 可切换）
- **全考试族注册表**：K12 各年级、中考、高考、KET/PET、CET4/6、考研、托福、雅思（AC/GT）
- **双向切换**：设置 / 考试页 / 首页均可 日常习得 ↔ 考试备考；`examProfile` 随设置云同步
- **官方薄题包**：`/api/exam/packs/{familyId}`（CET/雅思/高考/中考/KET/考研/托福等），按族解析
- **专项会话**：词汇 / 听力脚本 / 阅读短文客观题；错题自动入错题本 + FSRS
- **模考**：按题包 `mock.sections` 计时组卷
- **写作**：考试评分模板（IELTS 四维 / K12·CET 档次 / 通用）
- **口语**：数字人考官场景；社区 ECS 资料补充音频
- **进度**：备考主页展示练习量与模考次数
- **不做**：官方整套版权卷库打进 APK；已移除咖啡店冒险玩法

## 9. 单词本 / 词书 / 短语

- **单词本**：字幕收藏词、释义、音标/拼读、词根、发音
- **词书**：本地 + 云端下载；类型含词书 / 句型书 / 零基础；切换词书保留记忆
- **短语库**：按课筛选、掌握状态、发音、Anki 导出
- 复习设置（每日新学上限等）、Anki TSV/CSV/轻量包导出

云端：`/api/syllabus/catalog`、`/api/syllabus/books/{id}`

## 15. 云端共享与预生成（省算力）

| 能力 | 用户感知 | 接口要点 |
|------|----------|----------|
| B 站共享字幕 | 导入优先命中；ASR 后登录可贡献 | `GET/PUT /api/shared-subtitles/bilibili` |
| OCR 图书库 | 同一扫描 PDF sha256 复用 OCR 正文 | `GET/PUT /api/shared-ocr-books` |
| 阅读 TTS 缓存 | 相同句+音色少扣费 | `/api/reading/speech/*`、陪练 `tts/cache` |
| 句译 / 词卡 / 话题 | 透明加速 | `/api/pregen/*` |
| 语块 gloss | 静态语块中文释义预填 | syllabus JSON |

运营可在 ECS 播种推荐课官方字幕（见 `tools/subtitle/seed_recommended_bilibili_subs.py`）。

## 18. 说明与边界

1. **PRD 与实现**：`review-community-prd-v1.md` 等为规划稿；未落地细节以本仓库代码与测试为准。  
2. **运营依赖**：foundation/阅读示范音视频、推荐课字幕播种、媒体 manifest 需 ECS 侧配置后用户才「有声可听」。  
3. **版权与来源**：用户导入的影视与电子书需自行确保使用权；共享字幕/OCR 为学习缓存，非发行渠道。
