**可以。** 阅读与视频一样，用「固定垂直栏目 + 日更条目 + 更多 ›」。

**不冲突木纹书架：**

| 层 | 是什么 | 入口 |
|---|---|---|
| **我的库** | 木纹「我的书架」原样 | 侧栏 **阅读** 默认落地（已锁定） |
| **发现/荐书** | 分类栏目（类视频主页） | 书架顶「发现」/「荐书」；或阅读顶 tab：书架 \| 发现 |

## 信息架构

```
侧栏「阅读」
 ├─ 我的书架（木纹）← 默认
 │    · 已导入 / 在读封面
 │    · 导入
 │    · 统计
 └─ 发现（分类栏目，同视频纵向栏）
      · 每栏：横滑封面或双列卡 +「更多 ›」
      · 点书 → 详情/试读 → 一键加入我的书架
```

K12 教材书架仍走 **应试 → 目标** 或阅读内「教材」入口（见 feature-entry-map），不与发现栏目抢默认落地。

## 推荐栏目（骨架固定，条目日更）

对标 `video-home-categories.md`；偏阅读路径与现有 i+1 / 教材能力。

| 顺序 | 栏目 | 内容取向 | 角标 / 标签 |
|---|---|---|---|
| 1 | **刚好 i+1** | 按用户水平推的适读文/短篇 | `刚好 i+1` · 生词% · 词数 |
| 2 | **每日一文** | 短时文 **或** 在追书的「今日片」（见 `reading-daily-slices.md`） | 今日 · 可读时长 |
| 3 | **名著精读** | 长篇按 **日更切片** 连载；卡片推下一片而非整本 | `12/48` · 级别 |
| 4 | **故事 / 童话** | 叙事向短中篇 | 级别 |
| 5 | **新闻 / 时文** | 慢速新闻、校园时文 | i+1 · AI 审校（可） |
| 6 | **考试阅读** | 中高考生、四六级阅读篇 | 考种角标 |
| 7 | **有声读物** | 带朗读/跟读的书 | 有声 |
| 8 | **K12 教材精选** | 人教等课本配套短篇入口 | 年级 · 册 |
| 9 | **社区热读**（可选） | 社区热门在读书 | 在读人数 |

「更多 ›」→ 该栏目二级列表。卡片：封面朝外（可与木纹风格协调）或浅色卡；标签用 coral/teal tokens，不用小鹦霓虹绿。

## 源头：阅读 ≠ B站/YouTube

视频是平台流（B站 / YouTube）可持续抓新片。  
阅读**没有**对等的「书版 B 站」；现有源头是多路拼盘（见 `PRODUCT_FEATURES` §7.1 + `reading_source.py`）：

| 源头 | 是什么 | 适合栏目 | 「日更」真实含义 |
|---|---|---|---|
| **Standard Ebooks** + GitHub 白名单库 | 公版/许可电子书（ECS `/api/reading/source` 代理缓存） | 名著精读、故事 | 库缓慢增；**日更=从库轮换精选**，不是每天出一本新书 |
| **OneStop / Magic 等语料仓** | 分级短文语料 | 刚好 i+1、每日一文 | 池子大；**日更=按用户词库重排抽出 3 篇** |
| **AE 原创 starter** | `/api/reading/starter` 短章 | 入门 / 免费体验 | 人工扩写；可日更 1 篇原创或改写 |
| **本地导入**（txt/epub/pdf/OCR） | 用户自有书 | 只进木纹「我的书架」 | 不进发现策展 |
| **K12 教材 catalog + 时文月刊 PDF** | 课本配套 + `docs/时文英语` 等 | K12 / 考试阅读 | 月刊可**拆成每日一篇**；非平台实时流 |
| **从视频生成短文** | 有英文字幕的课 → 合成阅读篇 | 每日一文、新闻/时文 | 可跟视频日更联动 |
| **社区分享 / 考试薄包** | 用户帖、官方 exam packs | 社区热读、考试阅读 | 有投稿/题包即更 |

封面：Open Library 解析缓存（`/api/reading/covers/*`），与正文源分离。

**结论：** 发现栏目可以「看起来像视频日更」，但供应侧是 **池子轮换 + 分级抽取 + 少量人工/AI 日更**，不是爬一个书站首页。

## 日更怎么落地（建议流水线）

目标仍对齐视频：每栏每天约 **3** 条新露出；首页每栏 **4～6**；「更多」**20～40**。

1. **刚好 i+1（主引擎，可真·日更）**  
   - 输入：用户 FSRS/词库掌握度 + 候选池（OneStop / starter / 已入库公版短章 / 时文切片）  
   - 每天重算生词率约 2%–8% 的 Top N（产品已有 i+1 排序逻辑）  
   - **不依赖外网书站日更**

2. **每日一文（编辑/流水线日更）**  
   - 优先：时文月刊拆篇、视频字幕合成短文、AE 原创/改写  
   - 可选合规源：公开许可学习英语短讯（须法务过名单后再进 `allowed()`）  
   - 产出进 ECS `reading` 命名空间，App 只拉清单

3. **名著 / 故事（轮换，非日产新书）**  
   - Standard Ebooks 等固定库；每日换「本周精选 / 今日推荐」封面位  
   - 角标用级别·词数，不假装「今日新上架全书」

4. **新闻 / 时文**  
   - 短期：时文 PDF + 人工切片进库  
   - 中期：白名单 RSS/API → 分级改写 → 审校 → 上架（与视频字幕管线类似的「日更队列」）

5. **考试 / K12**  
   - 题包与教材 catalog 为存量；日更=按考种/年级轮换练习篇，不是新课本

6. **有声**  
   - 正文已在库 + ECS 朗读（CosyVoice）；日更=给当日 i+1/每日一文挂音频

加入书架后只出现在木纹「我的」；发现池降权归档，不删用户库。
