# 电视横屏学习 v1（A 档）+ 遥控器语音 v1.1

对照设计：`apps/mobile/design/tv_study_landscape.pen`（美剧精听 · 横屏 · 双语字幕）。

## 范围 v1

- 入口：设置 → **电视横屏学习**，或路由 `/tv`
- 播放：`/episodes/:id?tv=1` → `PadLandscapePlayerScreen(tvMode: true)`
- 锁定横屏；底部上一句 / 播放暂停 / 下一句 / 倍速 / 单句循环 / 跟读（D-pad 焦点）
- 右侧字幕区深色底，匹配 TV 稿

## 范围 v1.1（遥控器语音）

遥控器麦克风 = **按住说话（PTT）**，App 内自采麦（不依赖厂商助手）。

| 模式 | 行为 |
|------|------|
| **跟读** | 按住麦 → 录当前句 → 松手 → Voice 影子评分（若已配置）或打开跟读评分弹层 |
| **数字人** | 按住麦 → 录一轮 → 松手 → oral_coach `/turn`（需配置口语服务）；失败则提示去手机完整数字人 |

硬件键（尽量兼容）：`Microphone`、空格（调试）、部分盒子的 Voice Assist / Search。

UI：横屏底栏增加「按住跟读」「数字人说话」；录音中顶部提示条。

宽松策略：电视远场麦噪声大，跟读以 overlap / 完整度提示为主，文案标明「电视宽松模式」。

## 非目标

- Android TV Leanback 桌面 / 应用商店上架（B 档）
- 电视端完整 LiveTalking 形象渲染（形象仍以手机为主）
- 依赖小爱 / Google Assistant 热词唤醒当主路径

## 验收

1. `/tv` 大卡片可方向键聚焦  
2. `?tv=1` 横屏精听，返回 `/tv`  
3. 按住「按住跟读」或遥控器麦键：视频暂停、提示录音中，松手出结果或评分入口  
4. 「数字人说话」在已配置 oral_coach 时可走一轮对话；未配置有明确引导
