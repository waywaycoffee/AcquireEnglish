# 复习与社区开发进度

## A批次 第一版

已实现：

- 复习首页可按全部、单词、短语、句子筛选，选择会带入计划复习。
- 来源分组提供开始本组计划复习、自由练习本组。计划复习包括本来源到期与可新学内容，自由练习不修改FSRS。
- 同一收藏单词保留多个视频来源，不新增重复记忆卡；指定来源会使用对应原句、翻译、时间点，并可回看该视频。
- 完成页展示本轮实际保存的评分数量与分布，提供薄弱项自由练习和不含私有词句的成果文案预览/复制；不会自动发布社区。
- 保存失败恢复词卡多阶段评分快照，重试不重复累加本次阶段结果；原有防重复事务与评分成功后切卡保持。

验证：42项复习相关测试通过，覆盖指定来源隔离、二级视频来源、FSRS、保存失败、防重复、新学额度、暂停与响应式布局；本次修改文件静态分析没有error或warning。

## B批次 第一版

已实现正式同桌邀请、接受、拒绝、撤回、24小时过期与每天5次邀请限制。一人只能有一位正式同桌，数据库唯一约束保护并发接受；接受后其他关联待处理邀请自动失效。

共享学习时长、近期视频、收藏词库分别授权，默认关闭。解除或屏蔽后停止后续API访问共享数据；客户端不持久化对方的明细，切换账号清除页面状态，回到前台重新刷新。

一起上学可按近7/30天查看对方已同步的按天学习时长与近期视频记录。公开目录与已识别的公开视频导入显示标题，其余私有来源仅显示占位，不返回视频链接、原句或课程ID。当前统计仍是客户端同步值，不用于可信奖励、PK或战斗结算。

图书馆由本人明确操作同步当前收藏单词快照，不自动上传原句，取消收藏后重新同步可替换旧快照。支持共同/仅我/仅对方分类、搜索、数目对比和确认后收藏对方的词。每页最多50条，App支持搜索与继续加载，API使用offset分页；短语与测评估算后续接入，不把收藏数显示成真实词汇量。

入口：社区顶部“一起练”。可将自己的同桌编号告诉朋友，朋友在同一页面输入编号发起邀请，接受后各自设置共享开关。

验证：12项后端测试与46项App回归测试通过；后端部署后健康检查正常，同桌接口匿名请求返回401。APK构建成功，构建完成时没有连接Android手机，未声称安装成功。

另外修复词书异步初始化在Ref销毁后读取持久化状态的问题；回归测试已覆盖销毁时机。

### 数据与奖励规则

- 北京时间自然日。实际播放器进度事件才请求累计，服务端单次最多25秒且不超过墙钟间隔，不补录离线时长；页面停留本身不产生积分。
- 复习云备份成功后，根据近期评分、学习时钟和词卡去重生成核验记录；每日目标至多5条。活动证据仍源自客户端，不能证明用户真实注意力，不宣称已具备强反作弊能力。失败不回滚已保存的复习备份。
- 打卡、配对奖励、永久物品依靠唯一键和账本防重复。正式环境关闭旧的客户端直接申领积分接口；余额条件更新防止并发扣成负数。
- 七日活动从加入当天累计七个不同打卡日，不要求连续。两条活动共用个人打卡记录，退出再加入不重置或重复发奖。
- 大比武使用近7天服务端限速累计时长、去重词条与学习天数，100HP、最多12回合、±10%随机，接受时固定种子和属性。血条、攻击/格挡/实际扣血文字与战报一致；跳过和重播不重掷，不发胜负积分，装扮不加战力。
- 公开学习卡只接受B站BV号公开来源，不输出私人媒体地址。学习卡由用户明确填写表达和释义；原帖隐藏、删除或学习卡撤回后链接失效。浏览器答题不自动记入成绩。
- 正式环境不再创建示例用户和帖子，历史示例帖软隐藏；演示区交互不产生正式奖励。

### 隐私与管理

同桌学习明细默认不共享；PK另行双向授权。取消授权、退出或拉黑后服务端停止访问。账号切换清除对方明细和本地试穿，复习会话按账号隔离。公开学习成果不自动附带私有词条、视频或录音，默认只复制个人文案。

举报支持本人查看处理状态；管理员使用独立凭据查看待处理内容、写理由并下架/驳回，处理时间留档。线上凭据保存在服务器root专有文件`/root/acquireenglish-community-admin-token`，不进入App、Git或交付文案。用户可关闭站内互动提醒；没有开放自由私信。

### 当前边界（不冒充已交付）

- 六个AI卡通角色是整套静态基础模板，统一竖向contain显示；单件服装使用原有经典分层角色，试穿前提示切换。服装可以组合预览后一次保存。尚未交付AI角色通用分层衣服、专用坐姿/打斗逐帧素材或骨骼动画，大比武目前为前移、受击闪烁与回位动画。
- PK目前严格使用双方共同学过的词。不足5题提示继续学习/同步或扩大到30天；尚未开放双方确认后使用并集词。这避免未经另一方同意扩大词库使用范围。
- 图书馆展示收藏量、交差集；没有同版本测评数据时不推算真实词汇量。
- 治理首期覆盖帖子举报、屏蔽、人工下架与处理结果；评论单独举报、人物名申诉、自动审核和申诉工作流尚未交付。
- 公开卡支持免登录体验、App深链和继续学习；没有新建公开APK下载分发渠道，未安装App的访问者需使用既有安装渠道。
- 成果目前为可编辑文字卡；无需录音授权，也不自动生成分享图片。未做增长转化分析仪表盘。
- 陌生人实时匹配、自由私信、现金装扮、随机抽奖等按PRD首期范围后置。
