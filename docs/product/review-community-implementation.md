# 复习与社区开发进度

## A批次 第一版

已实现：

- 复习首页可按全部、单词、短语、句子筛选，选择会带入计划复习。
- 来源分组提供开始本组计划复习、自由练习本组。计划复习包括本来源到期与可新学内容，自由练习不修改FSRS。
- 同一收藏单词保留多个视频来源，不新增重复记忆卡；指定来源会使用对应原句、翻译、时间点，并可回看该视频。
- 完成页展示本轮实际保存的评分数量与分布，提供薄弱项自由练习和不含私有词句的成果文案预览/复制；不会自动发布社区。
- 保存失败恢复词卡多阶段评分快照，重试不重复累加本次阶段结果；原有防重复事务与评分成功后切卡保持。

验证：42项复习相关测试通过，覆盖指定来源隔离、二级视频来源、FSRS、保存失败、防重复、新学额度、暂停与响应式布局；本次修改文件静态分析没有error或warning。
