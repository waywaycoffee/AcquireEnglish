# 学习社区产品需求（V2）

版本：V2.1　日期：2026-11-21　状态：产品定稿（含开放问题拍板）  
承接：视频精听、FSRS 词库、i+1 可理解输入、一起练 / 同桌。  
**已下线：** 街角咖啡店闯关 / 冒险广场主叙事（不再作为产品能力或社区入口）。

---

## 0. 一句话定位

**不是打卡灌水社区，是「以素材和语言输出为载体、低压力、可溯源」的协作社区。**  
所有社区内容尽量能和产品内学习资产打通：视频片段、台词时间轴、生词卡、FSRS 词条、阅读短文。

底层原则：

1. **区分社交闲聊与语言练习**——拒绝变成纯打卡朋友圈。  
2. **优先服务三条闭环**：输入素材 → 导入学习；输出练习 → 获得反馈；难度匹配 → i+1 推荐。  
3. **游戏化克制**：保留同桌 / 一起练（积分装扮、词汇 PK）作为辅助动机；**不做咖啡店章节地图、闯关冒险广场、可开练闯关成果卡**。  
4. **克制内卷**：不做连续打卡排行、时长 PK、金币段位作为主界面。

## 3. 素材共享中心（根基，和播放器强绑定）

用户最愿意分享的不是空打卡，是**处理好的学习素材**。

### 3.1 素材包

可分享类型：

- 剧集 / 视频学习任务（**不存视频本体**，只存来源引用、时间轴、字幕、笔记）  
- 字幕文件、双语台词、听写稿、跟读脚本  
- 生词本（FSRS 词条、词频、CEFR）  
- 考试资料（归「考试」Tab，数据模型可复用素材包）

分享时自动 / 半自动元信息：

- CEFR、口音（美/英等）、题材、时长、生词密度  
- 推荐学法：精听 / 跟读 / 泛看 / 模考  

权限：公开 / 仅好友 / 私密。

**Fork：** 复刻到自己的库后可独立改字幕、加词；默认不影响原包。统计 fork / 收藏量用于信用，不用于灌水榜。

**同步上游（拍板：提供可选项）：**

- Fork 副本默认**不**自动跟随原作者更新。  
- 提供显式「同步上游」操作：用户可选择拉取原包词表 / 字幕等增量；冲突策略在实现稿中定义（建议：本地已改字段保留，未改字段可合并，并有预览确认）。  
- 原包删除后：已 fork 副本仍可用；同步上游入口变为不可用并提示原因。

### 3.2 发现与筛选

筛选：CEFR、口音、题材、时长、生词密度、是否有字幕、是否有配套词表、是否考试向。

推荐：**基于用户词库掌握情况的 i+1**，热度仅作次级信号；避免无脑推爆款。

订阅：关注创作者的素材更新流（关注关系 P1）。

### 3.3 评论区规则

素材评论区只欢迎**语言向点评**（连读、俚语、更好释义）；弱化无意义「加油打卡」。可用轻量模板引导。

### 3.4 版权与审核

- 社区**不存视频本体**；界面明确：用户自备本地 / 合法来源视频。  
- 举报：垃圾、广告、不当内容、侵权投诉入口。  
- 考试资料额外提示版权与用途边界。

### 3.5 验收要点

- 分享卡可一键导入播放器队列 + 可选导入词表到 FSRS。  
- Fork 后两端默认互不影响；删除原包不影响已 fork 副本。  
- 「同步上游」为可选、可预览、可取消。  
- 未登录可浏览合规公开素材元信息；写操作需登录。

## 4. 输出练习（核心价值：反馈）

### 4.1 轻输出（P1 优先）

| 类型 | 说明 | 联动 |
|------|------|------|
| 句子仿写 | 基于素材原句仿写；点评用词 / 语法 / 地道性 | 可绑素材时间戳 |
| 跟读投稿 | 一句 / 一段录音，支持与原声并排；点评重音 / 连读 / 语调 | 录音存 ECS，不进 APK |
| 选词造句 | 用社区或本人词库词造句 | **提交可绑定正在复习的 FSRS 词条** |

现网 `learning_result` 先承载「成果卡」；P1 拆出明确 kind：`imitation` / `shadowing` / `sentence_make`（或等价字段）。

### 4.2 点评身份（拍板）

- **不允许匿名点评**。点评必须绑定登录账号与可见身份（昵称 / 形象）。  
- 仍可控制作品可见范围（仅自己 / 好友 / 公开），但点评者身份不可隐藏。

### 4.3 重输出（P2）

- 短文写作：日记 / 观点；可标记不确定表达。  
- 口语长录音 + 转写：便于逐句批改（转写走服务端，音文件 ECS）。  
- 互评：  
  - 两种反馈：**语法纠错（客观）**、**地道度优化（主观）**  
  - 点评模板：【语法｜用词｜句式｜自然度】  
  - **批注版**（不覆盖原文）与可选「修改建议版」分离  
  - 优质点评者累积信用，优先获得他人反馈（缓解只发不评）

### 4.4 语言交换（P2+，控制范围）

- 双向：你练英、对方练中；按时区 / 等级 / 话题匹配。  
- 会话模板：话题、计时、录音留存、会话笔记 → 新词一键入 FSRS。  
- 防骚扰：会话上限、举报、拉黑；不做陌生人自由私信广场。

### 4.5 与「一起练」边界

| | 练习 Tab | 一起练 / 同桌 |
|--|----------|----------------|
| 目的 | 公开 / 半公开语言输出与互评 | 双人进度、装扮、趣味对抗 |
| 奖励 | 信用（有用点评、fork） | 积分装扮、打卡（可信时长） |
| 入口 | 社区顶栏「练习」 | 「我的」或顶栏学习桌图标 |

## 5. 学习动态（克制化）

- **默认成果动态**：整理了词表、仿写了 3 句、跟读求点评、完成短文。  
- 可选手动发「今天精听 20 分钟」类记录，**不强制、不上榜驱动**。  
- 可见性：仅自己 / 好友 / 公开。  
- 关注流（P1）：只看关注人的素材、输出、点评。  
- 统计分享：掌握词量、CEFR、听力时长——**自愿展示，不做榜单主叙事**。  
- 现有学习榜：保留「可关闭上榜」，入口藏在「我的」，文案禁止「段位 / 连续打卡王」。

## 6. 问答 & 讨论

1. 标签：发音、词汇、短语俚语、语法、表达辨析、素材推荐、学习方法、考试题型。  
2. 提问可嵌入：单词卡片 key、视频时间戳、台词摘录、自己的句子。  
3. 精选回答可沉淀；词条复习时可挂相关问答（P2）。  
4. 易混词专题帖（affect/effect 等）可共建，沉淀进知识库（P2）。  
5. 拒绝泛闲聊；无标签灌水可降权或限流。

---

## 7. 小组 / 房间

1. **固定小组**：按难度 / 题材 / 目标（B1 美剧精听、商务、雅思口语等）。  
2. **轻量任务**：本周共同素材、仿写话题、跟读段落；组内互评。  
3. **实时语音房**（P2+）：主持人、话题、计时；自愿录音；转写与重点表达可提取入词库。音视频一律 ECS。  
4. 权限：公开加入 / 申请 / 私密。  

**现网过渡：** 学习桌 + 「下周共同素材」卡片作为小组 MVP 壳，不宣称已有完整小组实体。**不以咖啡店闯关充当小组。**

## 9. 信用、治理与跨模块联动

### 9.1 信用（温和，非货币主循环）

正向信号：素材被 fork / 收藏、点评被标「有用」、语伴好评。  
**不**以发帖数为信用。  
一起练积分装扮继续独立存在，不与社区信用混成一种货币。  
**展示（拍板）：** 个人主页与「我的」资产页公开展示信用数值；同时可作为排序权重。不做信用排行榜主叙事。

### 9.2 治理

- 屏蔽：过高 CEFR、话题、用户。  
- 关键词过滤广告引流。  
- 举报：广告、人身攻击、低质灌水、不当内容；处理状态对举报人可追踪。

### 9.3 跨模块联动（差异化，必须分期落地）

1. 社区素材包 → 一键导入播放器 + 词表入 FSRS。  
2. 仿写 / 口语被点评的表达 → 一键入词库。  
3. 讨论例句 / 俚语 → 新建卡片，备注带讨论链接。  
4. 口语角 / 写作 → 识别生词，推荐入库（P2）。  
5. 复习 FSRS 时展示相关社区问答 / 仿写 / 例句（P2）。

音视频：**禁止打进 APK**；一律 `{media_cache_dir}/{namespace}/` + `/media/...`。

## 10. 分期与优先级

### P0（质量与叙事对齐，可快速交付）

1. 文案与空态全面对齐本稿定位（拒绝打卡灌水；考试 / 素材 / 练习边界清晰）。  
2. **清除咖啡店冒险入口与闯关文案**；游戏化仅保留同桌 / 一起练。  
3. Feed 作者 2D 形象稳定展示。  
4. 举报 / 拉黑 / 删除基础可用；分页与空态可靠。  
5. 版权提示：素材不存视频本体。

### P1（协作社区最小闭环）

1. 素材包 v1：元信息 + 权限 + fork + **可选同步上游** + 导入播放器 / 词表。  
2. 轻输出三种投稿 + 实名点评模板（批注不覆盖原文）。  
3. 问答嵌入词卡 key / 时间戳。  
4. 关注流 + 收藏素材。  
5. 「我的」公开作品列表（本人帖按 kind 聚合）+ **信用数值展示壳**。

### P2（深度与小组）

1. 重输出 + 转写；信用分算法与主页展示完善。  
2. 正式小组实体 + 组任务。  
3. FSRS 卡面关联社区讨论。  
4. i+1 素材推荐取代纯热度。  
5. 语言交换匹配（可控范围）。

### P3（实时与增长）

1. 主题口语角 + 存档入库。  
2. 易混词知识库共建。  
3. 推荐「不感兴趣」与新作者曝光。

### 明确不做（直到产品另开专项）

- 连续打卡排行、时长 PK、金币段位作为社区主界面。  
- **街角咖啡店闯关、冒险广场、章节地图、闯关成果卡。**  
- 陌生人自由私信、现金装扮抽奖。  
- 把视频文件缓存在 App 包内。  
- 用 mock 活跃人数冒充真实社区。  
- 匿名点评。

## 11. 成功指标（社区向）

优先看学习转化，不看刷时长：

1. 素材曝光 → 导入播放器 / fork 率  
2. 导入后 7 日内有效学习率  
3. 练习帖获得有效点评的比例  
4. 问答 24h 内首答率  
5. 社区用户次周学习留存（相对非社区用户）  
6. 举报处理时延  

Mock / 演示数据不进入上述指标。
