详细步骤（第一次安装）

  1. 准备一台 iPhone 或 iPad
    系统建议 iOS 15 及以上。用本人 Apple ID 登录 App Store。
  2. 安装 TestFlight
    打开 App Store，搜索「TestFlight」（开发者 Apple），安装蓝色飞机图标应用。 也可点上方「先安装 TestFlight App」。
  3. 用 Safari 打开邀请链接
    点本页「加入 TestFlight 内测」。若链接在微信里收到，请点右上角 「…」→「在 Safari 中打开」，否则可能无法调起 TestFlight。
  4. 接受邀请
    页面会打开 TestFlight，显示「爱快英语」。点 接受 / Accept。
  5. 安装 App
    接受后点 安装 / Install。桌面会出现「爱快英语」图标。 首次打开若提示「未受信任的企业级开发者」类提示，按系统引导允许即可（TestFlight 包一般为标准 Beta，通常不会出现）。
  6. 登录并反馈
    打开 App → 可用邮箱等方式注册/登录（审核演示也可用邮箱路径）。 把注册 ID微信发给作者 youyoufairytale， 并扫码加入「佑佑爸粉丝交流群」反馈 bug。

更新内测版本

  1. 打开手机上的 TestFlight App。
  2. 在列表中点「爱快英语」。
  3. 若有新构建，点 更新 / Update。

TestFlight 内测包大约 90 天后过期；到期前我们会发新构建，你在 TestFlight 里更新即可。

常见问题

  1. 点链接没反应 / 一直转圈？
    换 Safari；确认已登录 Apple ID；先单独打开一次 TestFlight App 再点链接。
  2. 提示「无法加入 Beta」？
    外测名额约 1 万；若已满请微信联系作者。或检查是否用错 Apple ID 地区账号。
  3. 能不能不装 TestFlight？
    外人一般不行。只有已登记 UDID 的设备才能装 Ad Hoc 包；公开测试请统一走 TestFlight。
  4. 这是正式上架吗？
    不是。当前是 TestFlight 外部 Beta。App Store 正式上架需另行提交审核。
