iPhone 怎么安装爱快英语

不用懂技术。因为 App 还没上苹果商店，需要先装一个苹果官方的「试用安装」小工具，再点一次按钮就能装上爱快英语。

重要：请用手机自带的 Safari 浏览器打开本页。
不要用微信里直接点开（微信内置浏览器经常装不上）。若在微信里看到本页：点右上角 ··· → 选择 在 Safari 中打开。

1先装「TestFlight」

这是苹果官方 App，专门用来装还没上架商店的试用版。名字叫 TestFlight（测试飞行），蓝色飞机图标。

去 App Store 安装 TestFlight

打开手机「App Store」→ 搜索「TestFlight」→ 点获取/安装。装好后先不用打开它。

2点下面蓝色按钮加入

点完会跳到苹果页面，再点「开始测试 / Start Testing」或「接受」。

点这里安装爱快英语

正在准备安装按钮…

3回到桌面打开 App

安装完成后，手机桌面会出现「爱快英语」。点开登录即可。 请把你的注册 ID发给作者微信 youyoufairytale，方便开通协助和收反馈。

以后有新版本：打开手机里的 TestFlight → 点「爱快英语」→ 点「更新」就行。

卡住了？看这里

  • 微信里点了没反应：右上角 ··· → 在 Safari 中打开，再点蓝色按钮。
  • 找不到 TestFlight：确认用的是中国区或你常用的 Apple ID，在 App Store 搜索英文名 TestFlight。
  • 提示无法加入：换个网络再试；或微信联系 youyoufairytale，作者可单独发邀请。
  • 安卓手机：不用这套流程，请去 下载页直接装 APK。
