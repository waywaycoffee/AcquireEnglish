Syllabus word / pattern / foundation books
==========================================

First-party study lists are hosted on the AcquireEnglish API
(`GET /api/syllabus/catalog`, `GET /api/syllabus/books/{id}`) and are
downloaded into local app storage only when the user chooses to.

They are NOT official Ministry of Education syllabus transcripts and must
not be marketed as such. Chinese glosses come from the offline dictionary
pipeline already shipped with the app. Rebuild source JSON with:

  python scripts/build_syllabus_books.py

Server copy lives under services/api/data/syllabus/.

Optional online catalog (user-initiated download only)
------------------------------------------------------
The in-app “开源词库” browser fetches lists from the community repo
https://github.com/lilinji/English on demand. Files are stored locally as
user word books. Content copyright remains with original authors /
publishers; personal study use only — do not redistribute commercially.
